A lighter week than the last few, but not a dead one.

Most of the visible activity was in [`agentwerk`](https://github.com/canvascomputing/agentwerk) — the minimal Rust crate for giving applications agentic capabilities. It picked up another push on Thursday and is sitting at 13 stars now, which is a nice signal that people are finding it useful. The work there is still focused on getting the core primitives right before adding higher-level abstractions.

On the malwi side, the main repo has moved from the `canvascomputing` org to my personal account as [`malwi-1`](https://github.com/leochilds/malwi-1). The org version is no longer public. Nothing dramatic — just a bit of project reorganisation as ownership of different pieces gets sorted out.

Elsewhere, I did a tidy of the projects page: added a bunch of older repos that were missing (some FreeCodeCamp exercises from 2020, some early tutorials from way back) and updated a few descriptions that had drifted from their GitHub counterparts.
