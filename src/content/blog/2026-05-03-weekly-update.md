Relatively quiet week, but a few things worth noting.

The most interesting new thing is [`input-output-binary`](https://github.com/leochilds/input-output-binary) — a brand-new repo I spun up on Wednesday. It's a sibling to [`bear-io`](https://github.com/leochilds/bear-io), taking the same "teach kids about computing concepts through an interactive demo" approach but focusing on binary input and output. Early days, but it's [live on GitHub Pages](https://leochilds.github.io/input-output-binary/) already.

[`LionPDF`](https://github.com/leochilds/LionPDF) got another push this week. It's been a steady focus lately — the Tauri + Rust stack keeps pulling me back in. There's something satisfying about the performance you get with native desktop apps, and Rust makes the hard parts feel manageable once you've got the patterns down.

Over at Canvas Computing, [`prompting`](https://github.com/canvascomputing/prompting) picked up a follow-up commit after last week's launch. The guide is settling into shape — it's already one of the more practical references I've put together for working with LLMs.

Nothing dramatic this week, but the projects are moving forward steadily.
